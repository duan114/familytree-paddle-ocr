Paddle GitHub 中文识别引擎 CH 更新

现有地址：https://duan114.github.io/familytree-paddle-ocr/

1. 解压 PaddleOCR_GitHub_Engine_20261110_CH.zip。
2. 在 familytree-paddle-ocr 仓库根目录上传 index.html、PaddleOCRAdapter.js、PaddleOCRWorker.mjs、PaddleEnginePage.js，以及 paddle-assets 文件夹中的文件，覆盖同名文件。
3. 大文件在 paddle-assets 文件夹中分批上传；每个单独文件均小于 GitHub 网页上传的25 MiB限制。不要把整个zip直接上传当作网站。
4. Commit changes，等待 Pages 构建完成，刷新原地址（必要时 Ctrl+F5）。显示“中文识别引擎已就绪”即可；模型按识别请求中的字形和模型设置选择。
5. 家谱程序也覆盖 CH 应用补丁或换用 CH 完整包，再刷新。GitHub地址无需改变。
6. 不覆盖原来的英文识别仓库；Cloudflare Worker /api/ocr 和试验用裁剪页不用改。

模型：
cht -> chinese_cht_PP-OCRv3_mobile_rec（独立繁体）
chs -> ch_PP-OCRv3_mobile_rec（标准中文，简体优先，不保证只输出简体）
mixed -> PP-OCRv5_mobile_rec（通用）
设置选择“始终使用v5繁简通用模型”时，无论字形选择均明确使用v5。

重要测试结果：专用模型能运行，但不一定更准确。在本次旧谱样张上，独立繁体v3明显弱于v5；如果旧谱识别变差，请在OCR设置切回v5通用模型。选择语言是识别前选权重，不做识别后的自动字形转换。

所有裁剪、选图与校对仍在家谱程序完成；GitHub页只负责浏览器内推理并返回文字/坐标。首次切换模型需要下载对应资产；图片不发往Paddle服务器。
